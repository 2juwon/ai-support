# 업무 프롬프트 공방

평소 하는 업무를 순서대로 적으면, ChatGPT·Claude·Gemini 같은 AI에 그대로 붙여 넣어 쓸 수 있는 **업무 프롬프트**로 만들어 주는 웹페이지입니다.

👉 https://2juwon.github.io/ai-support/

## 쓰는 법
1. 업무 이름과 작업 순서를 적습니다 (단계별로 / 자유롭게).
2. AI에게 줄 자료, 받고 싶은 결과, 역할, 말투, 지킬 것을 채웁니다.
3. **틀에 맞춰 바로 만들기**를 누르면 역할·목표·작업 순서·출력 형식·지킬 것·자료 틀로 프롬프트가 완성됩니다.
4. 복사해서 다른 AI에 붙여 넣고, `[[ ]]` 자리에 실제 자료를 넣어 쓰세요.

예시 3개(주간 보고 / 고객 문의 답변 / 회의록)를 눌러 보면 어떻게 나오는지 바로 볼 수 있습니다.

## 워크플로우로 옮기기
완성된 프롬프트를 거꾸로 작업 순서 칸으로 되돌립니다. 결과판의 **워크플로우로 옮기기** 버튼, 또는 위쪽 **가진 프롬프트를 워크플로우로 옮기기**에 다른 프롬프트를 붙여 넣어 씁니다.
- `# 역할`, `**작업 순서**`, `역할:`, `[자료]`처럼 제목이 있으면 브라우저가 바로 읽습니다(AI 안 씀). 번호 아래 세부 항목은 그 단계에 ` / `로 붙입니다.
- 제목이 없는 글은 AI로 읽고(`POST /api/extract`, AI 다듬기 횟수에서 1번), 그래도 안 되면 '자유롭게 적기' 칸에 통째로 넣습니다.
- 옮긴 뒤 **옮기기 전으로 되돌리기**로 원래 내용을 되살릴 수 있습니다.

## 공유하기
- **링크 복사**: 프롬프트와 작업 순서를 압축해 주소 `#p=` 뒤에 넣습니다. 서버에 아무것도 저장하지 않고, 받는 사람이 열면 그대로 채워집니다. claude.ai 안에서 만든 링크도 이 GitHub Pages 주소로 만들어집니다.
- **내용 복사**: 업무 이름과 쓰는 법 한 줄을 붙여 글로 복사합니다.
- **다른 앱으로 보내기**: 휴대폰 등 공유 창이 있는 브라우저에서만 보입니다.

## AI로 다듬기
- **GitHub Pages 버전**: 서버(`/api/refine`)가 Claude API(`claude-haiku-5-5`)를 대신 불러 줍니다. 글이 나오는 대로 화면에 보이고, '멈추기'로 끊을 수 있습니다.
  - 적은 내용('AI에게 줄 자료' 칸 포함)은 Claude로 보내기만 하고 서버에 남기지 않습니다. 횟수와 토큰 수만 셉니다.
  - 제한: 모두 합쳐 하루 300번, 한 사람(IP·브라우저) 하루 20번, 5초 간격. Claude 쪽 실패로 글이 하나도 안 나온 건 횟수에서 뺍니다. 숫자는 `server/wrangler.toml`의 `[vars]`에서 바꿉니다.
  - 주인 시험: `?dev=관리자비밀번호`로 한 번 열면 그 기기는 제한에서 빠집니다. `?dev=off`로 해제.
  - 프롬프트(규칙)는 서버 `server/src/refine.js`의 `META`가 씁니다. 페이지 안 `META`는 claude.ai용이라 둘을 같이 고칩니다.
- **claude.ai 아티팩트 버전**: 보는 사람 본인의 Claude 사용량으로 부릅니다(처음 누를 때 허용을 물음).

## 참고
- 저장한 프롬프트와 작성 중인 내용은 각자 브라우저(localStorage)에만 남고, 서버로 보내지 않습니다.
- HTML 파일 한 개로 되어 있어 따로 빌드가 필요 없습니다.

## 익명 통계 (GitHub Pages 버전)
프롬프트를 만들면 입력 내용 일부가 익명으로 서버에 모여 "사람들이 AI에게 맡기는 업무" 통계에 쓰입니다. 화면의 **익명 통계에 보태기** 체크를 끄면 아무것도 보내지 않습니다.

- 보내는 것: 업무 이름, 작업 순서(또는 업무 설명), 받고 싶은 결과, 역할, 말투, 지킬 것, 틀/AI 중 어떤 방법으로 만들었는지, 복사·저장을 눌렀는지, 브라우저마다 만든 무작위 익명 번호
- 보내지 않는 것: 'AI에게 줄 자료' 칸, 이름·로그인 정보. 이메일·전화번호·주민번호·9자리 이상 번호는 브라우저와 서버에서 두 번 가립니다. IP는 요청 제한에만 쓰고 그대로 저장하지 않습니다(해시)
- 예시를 그대로 누른 기록은 통계에서 빠지고, 같은 사람이 같은 내용을 30분 안에 다시 만들면 한 건으로 합칩니다
- claude.ai 아티팩트 안에서는 외부 서버 접속이 막혀 있어 수집하지 않습니다

### 서버 (`server/`)
Cloudflare Workers + Durable Object(SQLite, 무료 플랜). 주소 `https://ai-support.2juwon.workers.dev`

- `POST /api/log` 기록 남기기, `POST /api/log/:id/copy|save` 복사·저장 표시
- `POST /api/extract` 제목 없는 프롬프트를 워크플로우로 읽기 (`{form, left}`)
- `POST /api/refine` AI로 다듬기 (한 줄에 JSON 하나씩 흘려보냄: `{left}` → `{t}`… → `{done, truncated}` 또는 `{error}`)
- 관리 페이지 `/admin` (비밀번호 `ADMIN_KEY`): AI 다듬기 오늘·누적 횟수와 예상 비용, 요약 숫자, 날짜별 기록, 자주 나오는 낱말, 결과·역할·말투 순위, 기록 찾기·지우기, 엑셀용 CSV 받기
- `main`에 `server/`가 바뀌면 GitHub Actions '서버 배포'가 자동으로 올립니다. 저장소 Secrets에 `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `ADMIN_KEY`, `ANTHROPIC_API_KEY`(Claude API 키)가 필요합니다
- 시험: `cd server && npx wrangler dev --var ADMIN_KEY:test-key-123` 를 켜 두고 `node test/api.test.mjs`
- AI 시험(진짜 Claude 대신 가짜 서버): `test/refine.test.mjs` 맨 위 설명대로
